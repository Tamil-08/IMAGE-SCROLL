# IMAGE-SCROLL

A **smooth, responsive image scrolling gallery** implemented using HTML, CSS, and JavaScript.  
This project allows users to scroll through a horizontal sequence of images in a visually engaging way.

---

## 📌 Demo

You can view the demo by opening the `index.html` file in a browser or by deploying the project to GitHub Pages.

---

## 🚀 Features

- 📸 **Image scroll gallery** – images scroll horizontally (or vertically) based on user interaction
- 👌 Responsive and lightweight
- 🧩 Pure HTML & CSS implementation with no heavy dependencies
- 🎨 Ideal for portfolios, showcases, and creative websites

---

## 🧱 Technologies Used

- **HTML** – for structuring the layout
- **CSS** – for styling and scroll animations
- **JavaScript (optional)** – for interactive behaviors (if implemented)

> You can customize the scrolling behavior and transitions using CSS and JS.
